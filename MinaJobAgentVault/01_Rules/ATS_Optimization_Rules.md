# ATS Optimization Rules

> Load this file only during CV generation (Phase 3).

## What is ATS?
Applicant Tracking Systems scan CVs before a human reads them.
A CV must pass ATS first, then impress a human recruiter.

## Formatting Rules (ATS-safe)
- Use `.docx` or plain `.pdf` — no fancy design tools
- No tables, no columns, no text boxes
- No images, icons, or graphics
- No headers/footers with important info
- Use standard fonts: Arial, Calibri, Times New Roman
- Minimum font size: 10pt

## Keyword Rules
- Mirror the **exact phrasing** from the job description
  - Job says "ASP.NET Core" → use "ASP.NET Core" (not just ".NET")
  - Job says "CI/CD pipelines" → use that exact phrase
- Place keywords in:
  1. Profile summary
  2. Skills section
  3. Experience bullet points (naturally)
- Do NOT keyword-stuff — max 2–3 uses per keyword

## Section Header Standards
Use EXACTLY these headers (ATS recognizes them):
- `Work Experience` (not "Career History")
- `Education` (not "Academic Background")
- `Skills` (not "Technical Toolkit")
- `Languages`

## File Naming Convention
`CV_Mina_Tahmasebi_[CompanyName]_[Role]_[Date].md`
Example: `CV_Mina_Tahmasebi_Volvo_NETDeveloper_2026-05-20.md`
